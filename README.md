# 鼎盛公司排班管理系统

面向 **浙江鼎盛石化工程有限公司** 的网页版排班系统，纯前端实现，可部署到 GitHub Pages 作为公网链接使用。

## 功能概览

| 模块 | 说明 | 输出格式 |
|------|------|----------|
| 一级值班（干部值班表） | 公司级干部值班排版，管理员操作 | Word |
| 二级值班 | 9 个部门各自的二级值班排版，普通用户仅可操作本部门 | Word |
| 班组值班 | 各事业部班组夜间值班，多部门整合为多工作表 | Excel |
| 节假日值班 | 依据法定节假日日历 + 已有排班自动填充 | Excel |

## 账号与权限

- **管理员**（1 名）：默认账号 `admin` / `admin123`，可操作全部排班、人员管理、用户管理、数据备份。
- **普通用户**：可自行注册与注销，仅可操作本部门的二级值班与班组值班，以及查看/生成节假日值班。

## 人员管理

- 支持 Excel / CSV 导入导出（字段：姓名、联系电话、班组、部门）。
- 姓名 + 电话固定关联；班组、部门可单条或批量修改。
- 支持姓名 / 拼音 / 拼音首字母 / 电话 模糊检索。

## 使用说明

1. 打开网页，用管理员账号登录（首次请修改密码）。
2. 在「人员管理」中导入或录入人员信息。
3. 进入各排班模块，选择年份/月份（默认自动识别为下一月），从左侧拖拽人员到模板。
4. 周末 / 法定节假日日期自动标黄并标注「全天」，工作日标注「晚」，均可点击切换。
5. 导出 Word / Excel。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `paiban`）。
2. 将 `web/` 目录内的全部文件推送到仓库（或用 `main` 分支根目录）。
3. 在仓库 **Settings → Pages** 中，将 Source 设为 `main` 分支根目录，保存。
4. 稍等片刻即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问。

> 纯静态实现，无后端依赖，数据保存在浏览器本地（localStorage）。
> 如需多电脑之间共享数据，管理员可在「数据备份」中导出 JSON，在其它电脑导入。

## 本地预览

```bash
cd web
python -m http.server 8765
# 浏览器打开 http://localhost:8765
```

## 技术栈

- 原生 HTML / CSS / JavaScript（无构建步骤）
- docx.js（Word 生成）、SheetJS（Excel 生成）、pinyin-pro（拼音匹配）
- 法定节假日数据：国务院办公厅 2026 年节假日安排（国办发明电〔2025〕7 号）
